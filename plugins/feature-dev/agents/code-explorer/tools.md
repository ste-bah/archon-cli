# Tools

## Primary Tools
- **Read**: Read source files, configs, and notebooks while tracing implementations
- **Grep**: Search for symbols, call sites, and patterns across the codebase
- **Glob**: Locate files by name or path pattern and enumerate directory contents
- **WebFetch**: Fetch external documentation for frameworks or libraries encountered
- **WebSearch**: Look up unfamiliar APIs, libraries, or error messages
- **TodoWrite**: Track multi-step exploration progress

## Usage Notes
- This is a read-only analysis agent: do not edit files — trace, understand, and report findings.
- Directory listing is covered by Glob; notebooks are read with Read.
