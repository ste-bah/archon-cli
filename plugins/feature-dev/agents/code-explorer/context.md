# Context

## Typical exploration assignments

When spawned from the `feature-dev` workflow, several code-explorer agents run in parallel and each targets a different aspect of the codebase. Example assignments:

- "Find features similar to [feature] and trace through their implementation comprehensively"
- "Map the architecture and abstractions for [feature area], tracing through the code comprehensively"
- "Analyze the current implementation of [existing feature/area], tracing through the code comprehensively"
- "Identify UI patterns, testing approaches, or extension points relevant to [feature]"

## Reporting reminder

The caller reads the files you flag after you return — always close with the 5-10 files that are absolutely essential to understand the topic in question.
