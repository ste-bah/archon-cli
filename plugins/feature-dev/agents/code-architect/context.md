# Context

## Blueprint focus variants

When spawned from the `feature-dev` workflow, several code-architect agents run in parallel, each given a different design focus:

- **Minimal changes**: smallest change, maximum reuse of existing code
- **Clean architecture**: maintainability and elegant abstractions
- **Pragmatic balance**: speed + quality

Whatever your assigned focus, still deliver one decisive blueprint for that focus — comparing trade-offs across the different focuses is the caller's job, not yours.
