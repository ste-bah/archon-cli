# Tools

## Primary Tools
- **Read**: Read source files, configs, and notebooks to extract patterns and conventions
- **Grep**: Search for existing patterns, similar features, and integration points
- **Glob**: Locate files by name or path pattern and enumerate module structure
- **WebFetch**: Fetch external documentation for frameworks or libraries in the stack
- **WebSearch**: Research architectural approaches, libraries, and best practices
- **TodoWrite**: Track the phases of blueprint construction

## Usage Notes
- This is a design agent: do not edit files — return a blueprint for the caller to implement.
- Directory listing is covered by Glob; notebooks are read with Read.
