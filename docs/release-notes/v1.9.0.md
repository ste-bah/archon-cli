# v1.9.0

Minor release. A knowledge base stopped being two disjoint things. Corrections
stopped reinforcing rules nothing had been shown to cause. The Memory Garden
stopped deleting on its own. Replay started reading the latent surprise it had
been recording and discarding. The subagent runtime stopped doing the same work
five times a round. And the TUI grew a way to type a second line.

## Upgrade notes

**A correction no longer reinforces a rule unless something has been shown to
have caused it.** Reinforcement used to happen inside `record_correction`, on
the strength of a phrase match — so a correction nobody could explain still
moved a rule's score. Recording and reinforcing are now separate, and the live
path reinforces only on an accepted causal attribution. It fails closed: no
store, an expired budget, or a failed write all yield no verdict and therefore
no reinforcement. Two consequences worth knowing before you upgrade. The
extractor's deferred semantic pass now reinforces **nothing at all**, because it
records several turns late against an action window that has already moved, so
its corrections are permanently unattributable — a real reduction in what the
system learns, taken deliberately over reinforcing on a restatement nobody could
explain. And attribution itself runs in shadow: it names a cause, writes a row,
and mutates nothing else. Its rows are unadjudicated by construction, so
`causal_attribution_precision` reads as zero correct rather than a fabricated
1.0 (#77).

**Scheduled garden consolidation never deletes.** Decay and the three merges are
reversible, so they still apply directly. Staleness and overflow pruning call
`delete_memory` and restore nothing, so under the scheduler they become
proposals routed to a governed relation, reviewed through
`/garden proposals · approve · reject · apply · rollback`. Two independent
mechanisms hold this: the policy diverts before a delete is attempted, and the
scheduled budget hard-codes zero deletions as a constant rather than a
parameter. `/garden` run by hand is unchanged and still deletes. The scheduler
itself is **off by default** and reads as off in a config written before the
field existed (#79).

**The web workbench answers 403, not 200, when policy refuses an action.** Both
ingest handlers returned HTTP 200 with `accepted: false`, so any caller checking
only the status code read a refusal as success. Two sibling modules keep the 200
shape deliberately, because their frontends do read the flag and render the
reason — switching those would replace a readable explanation with a bare status
(#170).

**Enter still submits; Shift+Enter inserts a newline.** Alt+Enter is bound as
well, but Windows Terminal consumes it as its fullscreen toggle before archon
sees it, so on that terminal Shift+Enter is the working chord. Ctrl+L now forces
a full redraw. The input area grows to eight text rows with internal scroll,
down from a fourteen-row cap (#174).

**`reports/` is no longer tracked.** Audit and rescue reports were working
documents that should not have been committed. Nothing reads them — the
references in the R0 evidence file and the gate scripts are prose citations, and
the gate verifies closure against source, tests and git history.

## Knowledge bases are one namespace

"Knowledge base" meant two unconnected things: a directory under `.archon/kb/`
to the web UI, and a `kb_id` string in a Cozo relation to the CLI and TUI.
Neither surface read the other's storage and nothing anywhere enumerated the
names that existed — so a knowledge base was invisible wherever it was not
created, with no error, and a name you had not written down was unrecoverable
through any supported interface.

The listing is a union now. Origin is recorded on each row and never used to
filter, because how a knowledge base came to exist is not a reason to hide it. A
name present on both sides appears once, and where a directory slug and a stored
name differ the stored name wins, since that is what `--kb` matches. `archon kb
kbs` and `/kb kbs` surface it; the web Ingest tab and its header metric count
the same union.

An unreadable store warns rather than listing nothing, because "no knowledge
bases" is exactly what the bug being fixed looked like.

No migration is needed: existing command-line knowledge bases already have
membership rows and existing web ones already have directories, and the union
reads both (#170).

## The subagent runtime stopped repeating itself

None of this was latency-dominant — an LLM call dwarfs all of it — but at
fan-out scale it was real allocator, memory and I/O pressure.

Per round, whole-array copies of the conversation fell from five to two, and
full-history projections from two to one. The issue had assumed two copies;
there were five, one of which existed purely to be overwritten. The frozen tool
list is shared rather than deep-cloned about seventy schemas at a time, which
also makes its byte-stability structural — a shared immutable value cannot
drift. Token estimation no longer serializes the whole transcript twice a round.

Per spawn, a transcript opens **once** instead of once per message, the
ARCHON.md hierarchy is read once rather than once per agent, and a ten-way
fan-out of a three-query agent runs three memory-store searches rather than
thirty.

A twenty-round run over a 400KB transcript falls from 55.0ms to 16.4ms with peak
resident size down about a megabyte. Transcript writes of four thousand messages
halve. Serialized request bytes are byte-identical before and after, including
`cache_control` marker positions, verified by capturing every outbound body and
comparing hashes rather than by assertion (#171).

## TUI input

There was no keyboard path to a newline at all: Submit was bound to Enter and no
newline action existed. Shift+Enter appeared to send anyway because without the
kitty protocol most terminals encode it identically to Enter — the app received
a plain Enter and could not tell them apart.

Keyboard enhancement is pushed where the terminal supports it, and popping it is
proved rather than assumed: a harness re-executes the test binary as a child and
asserts on its own stdout bytes that pops equal pushes on clean exit, panic and
suspend. A terminal left in modified-keys mode outlives the process.

Fixing this surfaced a bug it would otherwise have shipped: key resolution missed
every `Repeat` event, so held backspace and arrows already did nothing — and
enhancement tags keypad Enter with a keypad state, which would have stopped
keypad Enter submitting the moment the flags went up (#174).

## Stray glyphs

Leftover cells, not input events. A full repaint now runs on the geometry
changes where the artifacts appeared, `Clear` sits under the suggestions popup,
and Ctrl+L forces a redraw.

No clear was added on resize: crossterm emits one event per column with no
coalescing, but ratatui's own autoresize already clears whenever the size
differs, so adding another would mean two full repaints per column of a drag.

The width bugs beside the status bar were the real source. The cursor counted
characters rather than columns, so it sat one column left of the glyph for every
double-width character; the session badge was sized in **bytes**, mis-anchoring
it at the right margin — which is where the reported stray `%` appeared (#174).

## Fixes

- A cached vector store now closes before the process tears down, and RocksDB's
  periodic stats dump is off. That single task caused two different crashes: a
  null dereference against a destroyed static map on Linux, and a deadlock
  against the CRT exit lock on Windows. Nothing reads what it wrote.
- `store_trajectory_batch` documented itself as one transaction and was a loop
  of N. It is one transaction now — 1600 guarded writes became four, and a test
  that took 16.18s takes 0.39s.
- The identity beta cache took an injectable root. The test suite had been
  overwriting and deleting the developer's real cache on every run.
- A typed workbench URL redirects to its page instead of answering 404, while a
  mistyped API path still 404s.
- The release-profile build in CI now runs only on a `[release]` commit or a
  manual dispatch, rather than at the tail of every push.

## What this release does not close

**#77 and #79 ship their code and stay open.** Both completion standards ask for
quantitative promotion evidence, and that evidence is a corpus of human
judgements that does not exist yet — 200 adjudicated attributions for R2, and
acceptance and reversal rates over real decisions for R4. What ships is the
machinery that produces those corpora: `archon cognitive adjudicate` is the
surface, and the metric rows are written on live paths. The numbers accumulate
in normal use. Nothing fabricates a population to clear a bar; an unpopulated
metric reports absent, and the release gate already rules that `NotEvaluated` is
not `Passed`.

**Alt+Enter is not universal.** Windows Terminal binds it to toggle-fullscreen
and consumes it. Making it work everywhere needs a third chord, which #174's
non-goals rule out.

**The splash screen writes symbols straight into the frame buffer**, bypassing
the wide-grapheme reservation — the one remaining draw path that could place a
double-width glyph without reserving its second column.
