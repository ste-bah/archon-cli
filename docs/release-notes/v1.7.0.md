# v1.7.0

Minor release. Four subsystems that had been built, tested and never called are
now wired and producing data; the KB's document intelligence gained real
commands; the VSCode extension can execute tools behind a permission prompt that
actually refuses; and a content-hash race in the shipping ingest path is closed.

## Upgrade notes

**The cognitive schema migrates on first open.** `cognitive_tick_audit` gains
nullable measurement columns and the schema version goes 1 → 3. Existing rows are
preserved, except that `dead_letters_replayed` and `self_model_updated` are set
to null for history written before this release — under the old code those were
hardcoded `0` and `true`, so every stored value was a fabrication rather than an
observation.

**`tools.bash_timeout` now has a floor.** The `timeout` argument on the Bash tool
is model-supplied, and used to be honoured downwards without limit — a guessed
two minutes silently overrode a configured hour. `tools.bash_timeout_floor`
(default 1800s) bounds it from below; the ceiling still wins when it is smaller.
Defaults move to `bash_timeout = 3600`.

**`[tools.cargo]` is new.** `CARGO_BUILD_JOBS` was a hardcoded `1` for every
agent-run cargo command on every host. It now comes from config, defaulting to
half the logical cores.

**Garden review-band adjudication is opt-in.** `auto_adjudicate_review_band`
defaults to off; it costs an LLM round trip on the session-start path.

## Wired what was already built

`ExecutiveLoop` classified, planned, scored, gated, executed, verified and
reflected — with seven test call sites and zero production callers. It now runs
as a joined shadow observer at the live turn boundary, bounded and observationally
inert: a no-op executor whose "success" can never become a persisted lesson.
`ReflectionWriter` was dead by inheritance and now triggers on correction,
repeated tool failure and bounded surprise, with raw chain-of-thought excluded by
type rather than by discipline. `SelfModelStore::write_fact` had never been called
outside a test and now has a production writer that refuses to invent a fact below
three verified observations (#76, #80, #81).

An abstaining correction classifier runs in shadow on every turn, sharing one
phrase table with the live heuristic so explicit-phrase recall holds by
construction (#78). A unified recall facade spans memory, docs, the knowledge
graph and the code index, with scores marked uncalibrated rather than invented
(#82). Cognitive metric events give every one of these somewhere to report (#83).

## Document intelligence

`archon docs compile`, `docs answer` and `docs export` now exist. The compile
pass (REQ-KB-002) and the Q&A engine with answer filing (REQ-KB-003) had been
implemented in April and never given a command; they read `doc_chunks` and write
results back through the docs stack, so compiled summaries and filed answers are
immediately searchable. `docs answer` streams as the model writes — first output
in ~2s against a ~6s total, where previously the terminal sat blank for the whole
duration.

## VSCode

`archon/prompt` runs the agent and streams text back. Tools execute behind a real
permission round-trip: `IdeAgentRuntime::new` takes the `Agent` by value and
installs the response channel on the way through, so there is no code path that
attaches a tool-capable agent with a fail-open gate. Denying a request stops the
tool (#26).

## Fixes

- A content-hash dedup race in `archon-docs` ingest: a bare read followed by an
  unguarded write at all three entry points, so two processes could create two
  documents for one hash. `#111` fixed the same race in a subsystem with no
  production consumer (#155).
- `CognitiveTick` reported success for two steps that did no work (#153).
- Test helpers wrote SQLite databases to a hardcoded `/tmp/`, which on Windows is
  the drive root — 32,758 orphaned files had accumulated (#156).
- Five hand-rolled markdown-fence strippers became one. Two were wrong: one
  silently dropped every memory from a turn whose model output carried a
  preamble.
- Compaction coverage gaps behind #37, and `/compact` now names `force` when it
  declines.

## Repository health

Every file is under the 500-line ceiling for the first time in months — sixteen
were split, each at a seam the file already had. The local `ci-gate.sh` is
runnable again after 30 clippy lints were cleared. Worth knowing: the size gate
CI actually runs scans only two directories and could not see most of those
files; `scripts/check-file-sizes.sh` is the one with real coverage.
